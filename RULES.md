## Component Reuse
Always reuse existing components before creating new ones. Check `src/components/` first and prefer extending or composing existing components over writing new ones.

## Spacing & Sizing
Use an 8px base grid for all spacing, sizing, padding, margin, gap, and border-radius values. For tighter spacing, 4px increments are acceptable. Avoid arbitrary values like 5px, 6px, 7px, 10px, 14px, etc. This does not apply to typography (font sizes, line heights).
